# C64 Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add a "C64" phosphor theme (light blue on blue) to the Phosphor picker.

**Architecture:** One new case in `PhosphorTheme`; `TerminalConfig.phosphor` / `.background` return the C64 colours for it. The settings picker iterates `allCases`, so the UI picks it up with no change. Verified by rebuilding the app bundle and inspecting a screenshot, since the app target has no tests.

**Tech Stack:** Swift, SwiftUI, SwiftPM.

**Spec:** `docs/superpowers/specs/2026-11-19-c64-theme-design.md`

## Global Constraints
- Label text exactly "C64".
- Rendered look: Colodore text RGB 120/105/196 on background RGB 62/49/162; configured values compensate for the bloom (see spec).
- No new `TerminalConfig` fields; no migration.
- Conventional Commits.

## Review Focus
- Old preferences with `"theme":"green"` still decode (raw-string enum; no test target for the app, verified by `defaults export` round trip is unnecessary: adding a case cannot break decoding of existing values).
- Monochrome colour mode on a bright background: ANSI backgrounds are `background + phosphor * l * 0.85` and can clip. Check visually with `ls --color` and a reverse-video run.
