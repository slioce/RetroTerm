# Tactile keyboard samples

All files are CC0 1.0 (public domain) recordings from Freesound, trimmed and normalised for RetroTerm. `press-NN.wav` plays for ordinary keys, `large-NN.wav` for space, return, backspace, tab and modifiers. They were taken from the HQ previews; the original lossless files can be downloaded from the pages below with a Freesound account.
